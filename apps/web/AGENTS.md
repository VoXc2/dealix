# Dealix public-web agent precedence

This scoped file applies to `apps/web/**` and refines the root `AGENTS.md`.

## Public truth authority
Use the current governed public source and Omega V3 architecture. `landing/public-surface-manifest.json` is the public-surface truth firewall; historical static pages, old demos, fixed prices/durations and fixed-five product framing are not public authority.

Current commercial path:
`Free Execution Diagnostic -> Qualified Discovery -> Customer-Specific Quote -> Outcome Sprint/Pilot -> Proof Review -> Dealix Runtime or Stop/Expand/Redesign`.

Current architecture:
`Dealix Holding -> Company Control Plane -> Sector Companies -> Arm Pods -> Specialist Logical Agents -> ResourceGovernor-bounded runtime workers`.

Rules:
- Never market Dealix as a fixed five-agent product. Historical five executor names are compatibility aliases only.
- Never reintroduce public fixed price, fixed pilot duration, live checkout, fabricated proof, unsupported accreditation/certification/residency, guaranteed ROI/revenue or government-access claims.
- Research/official Saudi market evidence may support educational/readiness content; it never proves a named buyer's intent, pain, compliance defect or relationship.
- Demo UI must not imply an email, meeting, payment, publication or external action actually occurred unless a verified receipt proves it.
- Source build success and HTTP 200 do not prove deployed release identity. Exact deployed Web/API SHA parity belongs to Production Trust.
- Preserve Arabic/English usability, evidence provenance, consent-aware CTAs and free/card-free diagnostic entry.

Do not deploy or publish from a coding worker. Public release/cutover remains exact action-bound L5.
