# Dealix Viral Partner Growth System — AR / EN

## Viral ≠ Spam
المقصود بالانتشار هنا أن كل شريك ناجح ومحتوى مفيد وتجربة تشخيص حقيقية يولد inbound جديدًا؛ لا يعني إرسال جماعي أو scraping.

## Loop A — Proof-to-Partner
1. Publish approved educational micro-content.
2. CTA to Partner Application / Free Diagnostic.
3. New partner sees transparent economics + rules.
4. Partner completes certification.
5. First qualified deal creates verified proof.
6. Approved proof becomes new content.

## Loop B — Sector Ambassador
لكل قطاع: 1 sector page + 1 diagnostic + 3 short-form scripts + 1 webinar outline + 1 case/proof format + 1 objections card. أفضل الشركاء يصبحون Sector Ambassadors بعد evidence/compliance، وليس بمجرد عدد followers.

## Loop C — Partner-to-Partner without MLM
الشريك يمكنه دعوة شخص آخر للتقديم عبر referral-to-program link للقياس فقط. لا يحصل على عمولة لمجرد التجنيد. إذا شارك لاحقًا فعليًا في صفقة نفس العميل يمكن attribution split موثق حسب قواعد الصفقة.

## Loop D — Challenge / Education
"اكتشف 3 عمليات في شركتك يمكن تحسينها بالـAI" → public educational tool → opt-in diagnostic → partner application cross-sell where relevant. لا نستخدم fake leaderboard أو جوائز مشروطة بشراء.

## Content Factory — Arabic-first
- 15–30 sec Reels/TikTok: مشكلة واحدة + مثال + CTA واضح.
- LinkedIn/X: teardown مهني أو checklist.
- YouTube Shorts: “متى AI يفيد شركتك ومتى لا؟”.
- Webinar: “كيف تحول علاقاتك B2B إلى فرص AI تنفيذية بدون أن تكون تقنيًا”.
- Partner success story: فقط بعد proof + publication consent.

## Viral Content Guardrails
كل أصل محتوى يمر على:
`CLAIMS_CHECK → DISCLOSURE_CHECK → PRICE_AUTHORITY_CHECK → PROOF_CHECK → CONSENT/PRIVACY_CHECK → BRAND_CHECK → PUBLISH_APPROVAL`.

## A/B Tests to Run
- CTA: “انضم كشريك” vs “سجل فرصة مؤهلة”.
- Hero: income angle vs professional-growth angle.
- Application length: 5-field quick vs 10-field qualified.
- Social proof placement.
- sector-specific vs generic landing pages.

Success metric = qualified activation and verified NCCR, not clicks alone.
