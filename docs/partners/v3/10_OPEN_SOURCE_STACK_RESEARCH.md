# Open Source / GitHub Stack Research — 17 Sep 2026

Use as components/references only; Dealix canonical economic/approval truth must stay in Company Machine.

## Referral / Affiliate Portal
### RefRef — AGPLv3
Pros: referral attribution, partner portal, rewards, fraud monitoring, manual reward approval, PostgreSQL/Next.js/Drizzle, Docker.
Use: UI/UX and fraud patterns; possible self-host evaluation.
Risk: AGPL obligations; review before embedding/derivative deployment.

### Refferq — MIT
Pros: affiliate dashboard, lead submissions, commission/payout states, white-label features, Next.js/PostgreSQL.
Use: benchmark and possibly components after security/code review.
Risk: payout integrations should not become economic truth or automatic bank authority.

### RefearnApp — AGPLv3
Pros: self-hosted affiliate tracking, analytics, Docker, PostgreSQL.
Use: architecture benchmark.
Risk: edge/cloud assumptions may conflict with self-host-only authority.

## Link Attribution
### Dub — open-source link attribution platform
Pros: mature link/conversion concepts, affiliate programs.
Use: link/attribution design reference or isolated service after privacy/security review.
Risk: stack includes external services; do not make it canonical ledger by default.

## E-signature
### Documenso — AGPL-3.0 core
Pros: self-hosted document signing.
Important: self-host requires signing certificate; docs warn operator is responsible for network security/SSRF/egress controls.
Use: later signing surface only after security threat model. Saudi electronic transaction validity still depends on proper identity/integrity/evidence implementation.

## Forms / Onboarding
### Formbricks — AGPLv3
Pros: self-hosted forms/surveys, integrations.
Use: partner application, training quiz, NPS/feedback; keep consent records in Dealix canonical ledger.

## Automation
### n8n — fair-code, self-hostable
Use: orchestration/adapters only; no independent economic authority. Pin production version and review licensing/security. Existing Dealix Company Machine remains source of truth.
