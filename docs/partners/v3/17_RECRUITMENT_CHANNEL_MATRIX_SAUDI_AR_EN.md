# Saudi Partner Recruitment Channel Matrix — AR/EN

## Goal
Recruit high-fit Saudi B2B partners through opt-in channels without scraping, spam, cold WhatsApp or misleading income promises.

| Channel | Motion | Evidence | Allowed? |
|---|---|---|---|
| Dealix public application page | inbound application | consent + application receipt | YES |
| QR at events/workshops | opt-in application | QR source + consent | YES |
| Existing warm network | human introduction | relationship evidence | YES |
| Sector communities | education + public CTA | public post + opt-in | YES |
| Universities / incubators | workshop + application | institutional permission | YES |
| Freelance communities | approved public recruitment post | source + opt-in | YES |
| Creator/educator partnerships | disclosed content | disclosure + approved claims | YES |
| Email to opted-in list | nurture | consent evidence + opt-out | YES |
| WhatsApp opt-in/inbound | follow-up | prior opt-in | YES |
| Cold WhatsApp | unsolicited direct marketing | none | NO |
| Scraped LinkedIn contacts | automated outreach | scraped source | NO |
| Purchased contact lists | mass outreach | weak/unknown consent | NO |
| Government employee influence network | compensated influence | conflict/influence | NO |

## Priority segments
- Saudi independent B2B consultants with lawful activity.
- Saudi agencies and professional-service firms.
- Sector specialists with buyer relationships and no conflict.
- Business creators/educators with relevant Saudi SME/enterprise audience.
- Technology implementation partners and integrators.

## Funnel
RESEARCH_ONLY → OPT_IN_APPLICATION → ELIGIBILITY_REVIEW → LEGAL_CLASSIFIED → TERMS_ACCEPTED → CERTIFIED → ACTIVE_PARTNER → FIRST_ACCEPTED_DEAL → FIRST_VERIFIED_COMMISSION.

## Recruiter operating rule
The recruiter may identify public communities and publish approved invitations only where the channel permits it. The recruiter does not infer consent from a public phone number, does not promise income, does not create a commercial agency relationship, and does not bind Dealix.

## KPI hierarchy
1. Qualified opt-in applications.
2. Legal-clear activation rate.
3. Certification completion rate.
4. First accepted deal-registration rate.
5. Verified partner-sourced collected cash / NCCR.
6. Time to first verified commission.
7. Compliance incidents per 100 activated partners.
8. Dispute rate and resolution time.

Raw contacts found, scraped profiles, messages sent and clicks are diagnostics only — never North Star metrics.
