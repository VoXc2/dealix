# Dealix Partner Sector Routing V2

Status: INTERNAL routing aid. Sector presence is not customer evidence and does not imply demand.
Use only to choose a diagnostic hypothesis; qualify the real problem before sales progression.

| Sector | Initial diagnostic angle | Evidence to seek |
|---|---|---|
| Technology / SaaS | AI adoption + support/revenue workflows | tool stack, backlog, support/sales friction |
| Retail / eCommerce | service, merchandising, ops automation | order/support/process bottlenecks |
| Hospitality | guest/service + back-office AI operations | response time, handoffs, repetitive work |
| Real Estate | lead-to-deal + property operations | enquiry routing, CRM gaps, handoffs |
| Construction | project/admin workflow intelligence | approvals, reporting, procurement friction |
| Manufacturing | operations/quality/knowledge workflows | downtime/admin/quality evidence |
| Logistics | dispatch/customer/exception workflows | delay handling, tracking, manual coordination |
| Healthcare | governed administrative AI only unless authority exists | admin burden, privacy/risk constraints |
| Professional Services | knowledge + proposal/delivery workflows | time-to-proposal, repeated analysis |
| Financial Services | governed ops/readiness under sector rules | approved process + compliance constraints |
| Education / Training | learner/admin/content operations | enrollment, support, content workflow gaps |
| Automotive | lead/service/after-sales workflows | response, booking, CRM/service handoffs |
| Food & Beverage | multi-site operations/customer workflows | ordering, staffing/admin, customer support |
| Tourism / Travel | multilingual service + operations | inquiry volume, itinerary/admin friction |
| Energy / Industrial | governed knowledge/operations support | approved use cases, safety/security boundaries |
| Telecom / IT Services | service desk + delivery automation | ticket, SLA, escalation and delivery data |
| HR / Recruitment | governed recruiting/admin workflows | screening/admin time, consent and fairness constraints |
| Accounting / ERP | FATOORA/process + workflow readiness | system integration, invoice/process evidence |
| Suppliers / B2G | procurement readiness / partner-or-no-bid | registration, qualification, tender evidence |
| General Saudi SME | AI operational readiness | top repetitive process, owner time, data readiness |

## Routing rules

- Start with the smallest diagnostic that can prove a qualified problem.
- Never state that a company needs a wedge because its sector appears in this table.
- Regulated sectors require the appropriate legal/compliance review before material claims or delivery.
- FATOORA relevance must be evidence-backed for the specific company; do not infer notification status.
- B2G remains Partner-or-No-Bid and never uses influence compensation.
- Any customer-specific commercial scope/price remains Dealix authority after Qualified Discovery.
