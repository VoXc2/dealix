# Dealix — Partner Onboarding V2

Authority: [`PARTNER_NETWORK_V2.md`](PARTNER_NETWORK_V2.md)

## Stage 0 — Application / Review
- [ ] Identity/business details reviewed.
- [ ] Partner motion selected: Scout / Growth / Co-Sell / Closer-Sector / Strategic.
- [ ] Sector focus recorded.
- [ ] Government/tender/conflict flags reviewed.

## Stage 1 — Covenant / Micro-certification
- [ ] Partner terms acknowledged after legal-approved version exists.
- [ ] Truth firewall: Research != Relationship; Quote != Payment; Won != Cash.
- [ ] PDPL direct-marketing consent + opt-out requirements understood.
- [ ] No cold WhatsApp, fake proof, guaranteed revenue/ROI or unauthorized pricing.
- [ ] B2G influence-compensation prohibition understood.

## Stage 2 — Enablement
- [ ] AR/EN pitch and qualification card delivered.
- [ ] Diagnostic wedge menu reviewed.
- [ ] Deal-registration workflow demonstrated.
- [ ] Commission/NCCR calculator logic reviewed.

## Stage 3 — First opportunity
- [ ] Relationship/consent evidence captured.
- [ ] Duplicate/existing-pipeline check completed.
- [ ] 120-day attribution protection recorded if accepted.
- [ ] Qualified problem hypothesis captured; no fake probability.
- [ ] Dealix diagnostic/discovery owner assigned.

## Stage 4 — Economic lifecycle
- [ ] Customer-specific quote authority remains with Dealix.
- [ ] Verified collection evidence attached before commission eligibility.
- [ ] NCCR deductions calculated.
- [ ] 30-day clearing satisfied or exception explicitly approved.
- [ ] Commission can be staged internally; bank payment requires external receipt.

## Performance review
Partner progression uses verified collected revenue, conversion quality, retention/customer
quality and compliance. Raw referral count alone never grants higher payout authority.
