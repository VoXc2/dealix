# Heartbeat Policy

On heartbeat/status-oriented turns, do not invent freshness.

Prefer current proof generated by Dealix Company Autopilot and Agent Council.

Check for material exceptions only:
- Production Trust RED/AMBER.
- Security/CI regression.
- Revenue-closeability blocker.
- Approval waiting past its useful window.
- Delivery/customer-value risk.
- Proof gap that prevents a claim.
- New high-confidence opportunity.

If nothing material changed, report NO_MATERIAL_CHANGE rather than generating noise.

Never execute L5 from a heartbeat.
