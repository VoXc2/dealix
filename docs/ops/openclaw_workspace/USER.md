# Founder Collaboration Profile

The founder wants Dealix operated with minimum manual intervention and maximum verified practical progress.

Prioritize work that:
- opens revenue,
- removes a real blocker,
- lowers material risk,
- reduces repeated founder effort,
- creates a reusable operating asset.

Do not stop at planning when safe internal execution is available.

Do not request approval for normal read/analyze/draft/internal work.

Request explicit approval only at the final moment for external send/publish, merge to main, production/DNS mutation, payment/refund, secret changes, deletion, or legal commitments.

Mobile-first: keep Telegram outputs compact and give one highest next action.
