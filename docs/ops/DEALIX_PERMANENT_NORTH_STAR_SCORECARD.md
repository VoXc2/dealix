# Dealix Permanent North Star Scorecard

This scorecard operationalizes `CASH_READY_AUTONOMOUS_DEALIX_COMPANY`. Targets are not evidence. All actual values must come from current verified receipts.

## Objective function

`Verified Economic Movement / Founder Minutes / Cost / Risk`

## Core scorecard

| Metric | Meaning | Evidence rule |
|---|---|---|
| VERIFIED_CASH_SAR | Cash actually evidenced | Payment evidence only |
| MRR_SAR | Verified recurring monthly revenue | Active recurring customer/payment evidence |
| GROSS_MARGIN_PCT | Delivery economics | Verified revenue and attributable delivery cost |
| QUALIFIED_FIRST_PARTY_CONVERSATIONS | Real conversations meeting current qualification contract | First-party interaction + qualification evidence |
| QUALIFIED_PROBLEMS | Specific painful business problem with accountable owner | Discovery evidence |
| CUSTOMER_SPECIFIC_QUOTES | Quote prepared for a named qualified customer | Quote artifact; quote is not invoice/payment |
| VERIFIED_PAYMENTS | Payments with evidence | Payment receipt/provider evidence |
| ACTIVE_PROJECT_CELLS | Governed active deliveries | Start authority + scope + owner |
| CUSTOMER_ACCEPTED_PROOF_PACKS | Proof accepted by customer | Customer acceptance evidence |
| PILOT_TO_EXPANSION_RATE | Accepted pilot proof converted to expansion | Customer decision evidence |
| FOUNDER_MINUTES_PER_VERIFIED_ECONOMIC_MOVEMENT | Founder intervention efficiency | Logged founder minutes / verified economic events |
| PRODUCTION_RELEASE_PARITY | Accepted intended release is actually deployed | Exact release identity |
| FRONT_DOOR_GREEN | Public canonical domains route correctly | TLS/routing/health/release evidence |
| DURABLE_CONSENT_GREEN | Consent/suppression runtime proven | Durable backend acceptance + policy evidence |
| TRUSTWORTHY_REQUIRED_CHECKS | Branch checks actually execute repository work reliably | Current check-run evidence |

## Milestone ladder

- **M0 — Trustable Front Door:** Production release identity, front door and durable consent proven.
- **M1 — Market Validation:** 5 qualified first-party conversations.
- **M2 — First Cash:** 1 verified paid pilot.
- **M3 — First Proof:** 1 customer-accepted proof pack.
- **M4 — Repeatability:** 3 verified paid customers/pilots with repeatable delivery evidence.
- **M5 — Q1 Revenue:** 24,000 SAR verified MRR with healthy margin and proof.
- **M6 — Q2 Revenue:** 60,000 SAR verified MRR.
- **M7 — Q3 Revenue:** 125,000 SAR verified MRR.
- **M8 — Scale:** 200,000+ SAR verified MRR.

## WIP law

- Executive top actions <= 3
- Deep commercial WIP <= 10
- Personalized diagnostics <= 3
- Live Project Cells <= 2
- Material approval packets <= 1
- Active GTM wedges <= 3
- Active capability benchmarks <= 1

## Commercial conversion chain

`Economic Signal -> Real Interaction -> Qualified Problem -> Diagnostic -> Discovery -> Customer-Specific Quote -> Verified Payment -> Delivery -> Customer Acceptance -> Customer Proof -> Expansion/Referral -> Productization`

No stage may be inferred from the stage before it.
